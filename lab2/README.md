# Лабораторная работа №2. Реализация базовых методов работы с массивами

## Цель работы

Изучение принципов реализации базовых методов работы с массивами с использованием колбэков: `forEach`, `map`, `filter`, `find`, `some`, `every`, `reduce`, а также закрепление навыков написания функций с корректным возвратом результатов и обработкой граничных случаев.

## Описание задания

Реализовать аналоги встроенных методов массивов JavaScript **без использования самих этих методов**. Разрешено использовать: цикл `for`, свойство `length`, обращение к элементам по индексу, метод `push`.

## Реализованные функции

### `printArray(array)`
Выводит элементы массива в консоль в формате:
```
Element 0: value x
Element 1: value y
```

### `printArray1(array)`
Выводит элементы массива в консоль в формате:
```
0:  x
1:  y
```

### `forEach(array, callback)`
Выполняет `callback(element, index, array)` для каждого элемента массива слева направо. Ничего не возвращает (`undefined`).

```js
forEach([1, 2, 3], (element, index) => {
  console.log(`Element: ${element}, Index: ${index}`);
});
// Element: 1, Index: 0
// Element: 2, Index: 1
// Element: 3, Index: 2
```

### `map(array, callback)`
Создаёт новый массив из результатов вызова `callback(element, index, array)` для каждого элемента. Длина результата совпадает с длиной исходного массива.

```js
const squared = map([1, 2, 3], (el) => el * el);
console.log(squared); // [1, 4, 9]
```

### `filter(array, callback)`
Возвращает новый массив из элементов, для которых `callback` вернул `true`.

```js
const even = filter([1, 2, 3, 4, 5], (el) => el % 2 === 0);
console.log(even); // [2, 4]
```

### `find(array, callback)`
Возвращает первый элемент, для которого `callback` вернул `true`. Если такой не найден — возвращает `undefined`.

```js
const first = find([1, 2, 3, 4], (el) => el % 2 === 0);
console.log(first); // 2
```

### `some(array, callback)`
Возвращает `true`, если хотя бы один элемент прошёл проверку. Останавливается при первом совпадении.

```js
const hasEven = some([1, 3, 4, 5], (el) => el % 2 === 0);
console.log(hasEven); // true
```

### `every(array, callback)`
Возвращает `true`, если все элементы прошли проверку. Останавливается при первом несоответствии.

```js
const allEven = every([2, 4, 6], (el) => el % 2 === 0);
console.log(allEven); // true
```

### `reduce(array, callback, initialValue?)`
Последовательно обрабатывает элементы массива, накапливая результат в аккумуляторе.

- Если `initialValue` передан — используется как начальное значение, обход с первого элемента.
- Если не передан — первый элемент становится аккумулятором, обход со второго.
- Если массив пустой и `initialValue` не передан — возвращает `undefined`.

```js
const sum = reduce([1, 2, 3, 4, 5], (acc, el) => acc + el, 0);
console.log(sum); // 15
```

## Контрольные вопросы

**1. В чём преимущества использования колбэков при работе с массивами?**

Колбэки позволяют отделить логику перебора массива от логики обработки каждого элемента. Это делает функции универсальными: одна функция `map` может превращать числа в квадраты, строки в верхний регистр или объекты в HTML — в зависимости от переданного колбэка. Код становится более читаемым, переиспользуемым и легко тестируемым.

**2. Какие проблемы могут возникать при использовании колбэков и как их избежать?**

Основные проблемы: потеря контекста `this` внутри колбэка (решается стрелочными функциями или `.bind()`), «callback hell» при глубокой вложенности (решается промисами и `async/await`), а также передача некорректного аргумента вместо функции (решается проверкой `typeof callback === 'function'` с выбрасыванием `TypeError`).

**3. Как реализовать функции `map`, `filter`, `find`, `some`, `every`, `reduce` без встроенных методов?**

Все функции реализуются через обычный цикл `for` с итерацией по индексам от `0` до `array.length - 1`. На каждом шаге вызывается `callback(array[i], i, array)`. Разница лишь в том, что делается с результатом: `map` — кладёт в новый массив через `push`; `filter` — кладёт только если колбэк вернул `true`; `find` — сразу возвращает элемент; `some`/`every` — возвращают булево значение с ранним выходом из цикла; `reduce` — накапливает значение в переменной-аккумуляторе.
