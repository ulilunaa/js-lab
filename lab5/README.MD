# Лабораторная работа №5. Работа с DOM-деревом и событиями в JavaScript

## Цель работы

Ознакомление с основами взаимодействия JavaScript с DOM-деревом на основе веб-приложения для учёта личных финансов.

---

## Описание задания

Разработать одностраничное веб-приложение для учёта доходов и расходов. Приложение позволяет добавлять транзакции через форму, отображать их в таблице, удалять и просматривать полные детали.

## Описание модулей

### `utils.js`
Вспомогательные функции:
- `generateId()` — генерирует уникальный идентификатор транзакции на основе `Date.now()` и случайной строки.
- `formatDate(date)` — форматирует объект `Date` в строку вида `DD.MM.YYYY HH:MM`.
- `getFirstWords(text, n)` — возвращает первые `n` слов из строки (по умолчанию 4).

### `transactions.js`
Работа с массивом транзакций:
- `transactions` — массив объектов транзакций (`id`, `date`, `amount`, `category`, `description`).
- `addTransaction(amount, category, description)` — создаёт объект транзакции и добавляет его в массив.
- `removeTransaction(id)` — удаляет транзакцию из массива по `id`.
- `getTransactionById(id)` — возвращает транзакцию по `id` или `undefined`.
- `calculateTotal()` — вычисляет общую сумму всех транзакций.

### `ui.js`
Работа с DOM:
- `renderTransaction(transaction)` — создаёт строку таблицы и добавляет её в `tbody`. Строка окрашивается в зелёный (доход) или красный (расход) цвет. В столбце описания отображаются первые 4 слова.
- `removeTransactionRow(id)` — удаляет строку таблицы по `data-id`.
- `renderTotal(total)` — обновляет отображение общей суммы.
- `renderTransactionDetail(transaction)` — показывает полное описание транзакции в блоке деталей.
- `hideTransactionDetail()` — скрывает блок деталей.
- `showFormError(message)` / `hideFormError()` — управление сообщениями об ошибках формы.
- `resetForm()` — сбрасывает поля формы.

### `index.js`
Точка входа. Импортирует модули `transactions` и `ui`, навешивает обработчики:
- **Submit формы** — валидирует данные, создаёт транзакцию, отрисовывает строку и обновляет баланс.
- **Делегирование событий на `<table>`** — обрабатывает клик по кнопке удаления и клик по строке для просмотра деталей.

## Контрольные вопросы

**1. Каким образом можно получить доступ к элементу на веб-странице с помощью JavaScript?**

Основные способы: `document.getElementById('id')` — по уникальному идентификатору; `document.querySelector('селектор')` — по CSS-селектору, возвращает первый найденный элемент; `document.querySelectorAll('селектор')` — возвращает все совпадающие элементы в виде `NodeList`. В проекте используется `querySelector` как универсальный и читаемый способ.

**2. Что такое делегирование событий и как оно используется для эффективного управления событиями?**

Делегирование событий — это приём, при котором обработчик навешивается не на каждый дочерний элемент отдельно, а на их общего родителя. Событие всплывает от дочернего элемента к родителю, где обработчик через `event.target` определяет, что именно было нажато. В данной работе один обработчик на `<table>` обрабатывает и клики по кнопкам удаления (`.btn-delete`), и клики по строкам (`tr[data-id]`). Это эффективно, потому что не нужно навешивать и снимать обработчики при динамическом добавлении/удалении строк.

**3. Как можно изменить содержимое элемента DOM с помощью JavaScript после его выборки?**

После получения ссылки на элемент через `querySelector` можно изменить его содержимое: `element.textContent = '...'` — для замены текстового содержимого (безопасно, не интерпретирует HTML); `element.innerHTML = '...'` — для замены HTML-содержимого (позволяет вставлять теги). В проекте `innerHTML` используется для отрисовки блока деталей транзакции, а `textContent` — для обновления суммы баланса.

**4. Как можно добавить новый элемент в DOM-дерево с помощью JavaScript?**

Стандартный способ: создать элемент через `document.createElement('tag')`, задать ему атрибуты и содержимое, затем добавить в нужное место через `parentElement.appendChild(newElement)` (в конец) или `parentElement.insertBefore(newElement, referenceElement)`. В проекте каждая новая транзакция создаётся как `<tr>` через `createElement` и добавляется в `tbody` через `appendChild`.
