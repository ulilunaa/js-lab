# Лабораторная работа №4. Продвинутые объекты в JavaScript

**Цель:** познакомиться с классами и объектами в JS, наследованием, конструкторами и методами.

## Запуск

```bash
node src/index.js
```

Node.js должен быть установлен. Сторонних зависимостей нет.

## Структура

```
src/
  classes.js   — классы Item, Weapon + функции-конструкторы
  index.js     — тесты и демонстрация работы
```

## Что реализовано

**Шаг 1 — класс `Item`**

Базовый класс предмета. Поля: `name`, `weight`, `rarity`. Методы: `getInfo()` возвращает строку с описанием, `setWeight()` меняет вес (с проверкой, что значение > 0).

**Шаг 2 — класс `Weapon`**

Наследует `Item`. Добавляет `damage` и `durability`. Метод `use()` снижает прочность на 10, `repair()` восстанавливает до 100. `getInfo()` переопределён — включает урон и прочность.

**Шаг 3 — тестирование**

В `index.js` создаются несколько объектов обоих классов, вызываются все методы, проверяются граничные случаи (сломанное оружие, нулевой вес).

**Шаг 4 — опциональная цепочка и функции-конструкторы**

Опциональная цепочка `?.` используется в функции `safeGetInfo()` — если передать `null`, ошибки не будет, просто вернётся `undefined`.

Классы `Item` и `Weapon` переписаны в стиле ES5 через функции-конструкторы. Наследование настраивается вручную через `Object.create()` и `call()`.

## Ответы на контрольные вопросы

**1. Какое значение имеет `this` в методах класса?**

`this` указывает на конкретный экземпляр, для которого вызван метод. Если `sword.getInfo()` — то `this` это `sword`. Проблемы начинаются, когда метод передаётся как колбэк — тогда `this` теряется, и нужно либо `.bind()`, либо стрелочная функция.

**2. Как работает модификатор `#` в JavaScript?**

Поля и методы с `#` становятся приватными — к ним нельзя обратиться снаружи класса, иначе `SyntaxError`. Это не просто соглашение как `_`, а реальное ограничение на уровне языка. Появилось в ES2022.

```js
class Item {
  #secret = 42;
  getSecret() { return this.#secret; }
}
const i = new Item();
i.#secret;      // SyntaxError
i.getSecret();  // 42
```

**3. В чём разница между классами и функциями-конструкторами?**

По сути — почти никакой, `class` это синтаксический сахар над прототипами. Разница в удобстве: с классами не нужно вручную настраивать `prototype` и вызывать `Parent.call(this)`. Ещё классы не hoisting-ятся как функции, и внутри них всегда строгий режим. Приватные поля через `#` тоже только в классах.
